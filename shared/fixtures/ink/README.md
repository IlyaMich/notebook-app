# FMT-04 CP2 — Canonical ink fixtures

These files implement the **synthetic, platform-independent** fixture suite described in
`docs/architecture/notebook_ink_contract_v0_1.md`.
They use the existing provisional `.notebook` `schemaVersion: 1` archive format,
not a Jetpack Ink or PencilKit native serialization.

## Contents

- `valid/*.notebook`: six expected-valid packages covering pen, pencil,
  highlighter, pressure, optional characteristics, repeated timestamps,
  single-point strokes, and ownership on mixed-size pages.
- `invalid/*.notebook`: eleven expected-invalid packages covering bad timestamps,
  unsupported ink, malformed values and missing/invalid required stroke data.
- `expected_results.json`: each fixture's expected result, rationale, and an
  optional message fragment for the **current Python** validator.
- `../build_ink_fixtures.py`: standard-library generator. All ZIP entries use
  fixed metadata and stored (uncompressed) content so generated bytes are stable.

The two deliberately nonfinite invalid packages contain `NaN` / `Infinity`
JSON tokens. These are **not valid canonical JSON numbers**: they exist solely
so import/validation rejects them.

## Verify from the repository root (PowerShell)

First verify the committed files match the deterministic generator:

```powershell
py -3 shared/fixtures/build_ink_fixtures.py --check
```

Expected: `PASS: 17 deterministic FMT-04 ink packages and catalog`.
If intentionally editing fixture definitions, regenerate them with
`py -3 shared/fixtures/build_ink_fixtures.py --write` and review the diff.

Then exercise the **existing** validator against each package:

```powershell
$catalog = Get-Content shared/fixtures/ink/expected_results.json -Raw | ConvertFrom-Json
foreach ($item in $catalog.valid) {
    $fixture = "shared/fixtures/ink/$($item.path)"
    & py -3 shared/validators/validate_notebook.py $fixture
    if ($LASTEXITCODE -ne 0) { throw "Expected valid: $fixture" }
}
foreach ($item in $catalog.invalid) {
    $fixture = "shared/fixtures/ink/$($item.path)"
    $result = & py -3 shared/validators/validate_notebook.py $fixture 2>&1
    if ($LASTEXITCODE -ne 1) { throw "Expected rejection: $fixture" }
    if (($result -join "`n") -notlike "*$($item.error_contains)*") {
        throw "Wrong error category for $fixture : $result"
    }
    Write-Host "PASS rejected: $fixture"
}
```

Finish with the existing regression suite:

```powershell
py -3 -m unittest discover -s shared/validators/tests -v
```

Do **not** import invalid packages into your working app library. The fixture
suite is synthetic and intended for shared-format validators and later native
adapter tests.

## Expected semantic outcomes

| Contract ID | Fixtures | Expected |
|---|---|---|
| INK-01 | `ink_pen_straight_v1` | Accepted; straight pen samples and brush preserved |
| INK-02 | `ink_pen_curve_v1` | Accepted; curved geometry, pressure and equal timestamps preserved |
| INK-03 | `ink_pencil_tilt_v1` | Accepted; signed orientation and tilt preserved |
| INK-04 | `ink_highlighter_v1` | Accepted; translucent highlighter |
| INK-05 | `ink_single_sample_v1` | Accepted; one point is legal |
| INK-06 | `ink_single_sample_v1`, `ink_highlighter_v1` | Accepted; missing optionals remain absent |
| INK-07 | `ink_decreasing_time`, `ink_negative_time` | Rejected |
| INK-08 | nonfinite coordinate, pressure/tilt/width, empty points cases | Rejected |
| INK-09 | `ink_unknown_encoding`, `ink_unknown_brush` | Rejected; never silently discarded |
| INK-10 | Repeated unedited serialization | CP3 automated test; not proven by fixture validation alone |

`ink_page_local_v1` also tests distinct page IDs, different page dimensions,
explicit element ownership/order, and a non-identity element transform.

**Out of scope:** Native capture, brush appearance, pressure calibration,
low-latency rendering, actual stylus/palm rejection, and cross-platform
round trips. FMT-04 CP3 adds permanent automated validator tests. EDT-05 and
EDT-04 later measure native fidelity.

The existing FMT-03 `shared/fixtures/valid/`, `shared/fixtures/invalid/` and
`shared/fixtures/expected_results.json` are intentionally unchanged: the
FMT-03 regression suite requires its own catalog to exactly match those folders.
